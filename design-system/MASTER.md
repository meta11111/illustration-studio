# Дизайн-система «Собрано»

Источник рекомендаций: UI UX Pro Max, commit 3327f9d. Генератор был запущен для creative design editor. Его рекомендации о кинетическом брутализме адаптированы под рабочий редактор: интенсивное движение отвлекает от композиции и мешает сравнивать палитры.

## Принципы
- Редактор как современная мастерская: тёмная верхняя полоса, тёплый фон, светлые панели и холст, который остаётся главным.
- Один акцент для создания композиции, другой для экспорта; встроенные палитры меняют иллюстрацию, но не интерфейс.
- Простые подписи, явные состояния выбора, крупные области нажатия, видимый фокус.
- Заголовки Space Grotesk, текст DM Sans. Системные шрифты остаются запасным вариантом.

## Токены
- Ink #17231f; workspace #f1f1eb; surface #fffefa; soft #f4f6ef.
- Primary #145e47; hover #237c5d; on-primary #ffffff.
- CTA #d9ef91; on-CTA #17231f; line #dbe2d8; muted #52635d; danger #aa3546.
- Радиус 9–22 px; отступы по шагам 4/8 px; переходы 200 мс, отключаются при reduced motion.

## Приёмка
Проверить 375, 768, 1024 и 1440 px, клавиатурный фокус, контраст текста, drag на холсте, импорт JSON, экспорт SVG и сохранение исходной геометрии.
