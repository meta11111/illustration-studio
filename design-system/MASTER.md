# Дизайн-система «Векторная студия»

Основа: UI UX Pro Max, commit 3327f9d. Направление уточнено по референсам Ярослава: кинетическая студия с крупной типографикой, светом, объёмными действиями и живыми векторными иллюстрациями. Автоматическую рекомендацию брутализма используем избирательно: motion на первом экране и в состояниях, точность управления внутри редактора.

## Принципы
- Первый экран — тёмная сцена с тёплым свечением, типографикой и оригинальными векторами из задания. Новая растровая графика не подменяет исходные объекты.
- Яркое действие одно: открыть редактор/собрать. Кнопка имеет объём через градиент, внутренний блик, нижнюю грань и тень, текст жирный и контрастный.
- На холсте сохраняется оригинальная SVG-композиция; анимация и свет относятся только к интерфейсу, не попадают в экспорт.
- Анимация использует transform/opacity, плавные циклы и короткие отклики. При reduced motion циклы отключены.

## Токены
- Фон #111012; панели #1b191c; светлый текст #f7f4f1; линии #373439.
- Ember #ff713c, hover #f45b25, тёплые тени; холст остаётся фоном выбранной палитры.
- Space Grotesk для крупных заголовков и меток, DM Sans для интерфейса. Радиусы 5–18 px.

## Проверка
- Контраст, видимый фокус, подписи и aria-label для иконок, клавиатурные действия, 375/768/1024/1440 px, reduced motion.
- Вручную: переход к редактору, сборка, библиотека, drag, палитры, роли, импорт JSON, экспорт SVG в Figma.
