# Локальный подбор и раскладка

## Что реализовано

Модуль src/composer.js работает полностью локально, без ключей, сетевых запросов или генерации изображений.

Два сценария:
- names: точные предметы, синонимы и распространённые русские формы слов;
- metaphor: подбор предметов по конечному смысловому словарю.

Словарь покрывает десять тем: обучение/знания, финансы/сбережения, совместная работа, объединение частей, идеи/вдохновение, общение/связь, музыка/внимание, порядок/работа, забота/благодарность, записи/документы. Это детерминированный поиск по правилам, а не языковая модель общего назначения.

Предметы: книга, телефон, пазлы, монета, наушники, лампа, цветы, кошелёк, папка, ручка. Фактически доступный набор всегда ограничен переданным каталогом. Недоступные assetId исключаются.

Примеры:
- «Книга, смартфон, пазлы» — три названных предмета.
- «Собрать знания воедино» — книга и пазлы с дополнительными учебными предметами.
- «Как накопить сбережения» — кошелёк и монета.
- «Совместная работа в команде» — пазлы, папка, телефон.
- «Книга и дракон» — книга плюс предупреждение о неизвестном драконе.
- «Книга без телефона и ручки» — только книга.
- Неизвестная метафора — пустой результат с объяснением, без случайной подмены и новых объектов.

## API

analyzePrompt({prompt,mode,subjects}) возвращает selected, matchedIds, excludedIds, concepts, confidence, warnings, explanation, engine:'local'.

confidence означает:
- high: предметы названы явно;
- medium: есть совпадение с конечным словарём тем;
- none: нет подходящих предметов.

composeScene({prompt,mode,subjects,width,height,detail,seed,includeBackground}) дополняет анализ полями objects, scale, status и template.

Объект имеет id, assetId, x, y, rotation, role. Координаты x/y — центр предмета на холсте. status:'no-match' означает, что UI должен сохранить текущую сцену и показать предупреждение. status:'ok' разрешает заменить список объектов.

Все экземпляры используют один общий scale, индивидуального масштаба в объекте нет. Ширина/высота берутся из реальных SVG-каталогов. Для S используется множитель 2, приводящий исходный размер S к той же системе координат, что и L. Исходная разница геометрии S/L сохраняется.

## Раскладка

Используются шаблоны для квадратного, горизонтального и вертикального холста. Seed детерминированно выбирает вариант. Главный предмет остаётся смысловым центром; остальные распределяются с учётом площади исходной геометрии.

Общий коэффициент масштаба ограничен доступной областью каждого слота и повёрнутыми габаритами. Все предметы сохраняют отношения исходных размеров. Наложения допустимы и намеренны, формы не меняются.

Третий и последующие по смысловому рангу предметы получают фоновую роль, если она доступна и includeBackground=true. Фоновые экземпляры помещаются раньше главных в списке слоёв.

## Проверки

tests/composer.test.mjs — node:test без внешних зависимостей:
- русские формы и синонимы;
- неизвестные предметы, в том числе рядом с известными;
- отрицания и списки исключений;
- пустая/неизвестная метафора;
- объяснимый тематический подбор;
- детерминизм и варианты;
- только исходные ID и уникальные экземпляры;
- отсутствие индивидуального масштаба;
- одинаковые относительные размеры S/L;
- габариты после поворота в трёх форматах;
- фоновая роль и ограниченный каталог.

Запуск: node --test tests/composer.test.mjs

## Расширение свободного понимания метафор

Для свободных формулировок за пределами словаря можно добавить отдельный серверный адаптер LLM. Ему передают запрос и краткий разрешённый каталог. Он возвращает структурированный список assetId, ролей, приоритетов и объяснение. Список проверяется по схеме и каталогу, после чего используется тот же геометрический раскладчик.

Ключ хранится только на сервере. Модель не должна возвращать SVG, контуры, неизвестные предметы или индивидуальные масштабы. Ошибки и таймауты не должны менять текущую сцену. Локальный словарь остаётся явным резервным режимом.

Такой адаптер в текущем модуле не реализован; никаких фиктивных вызовов модели или обещаний неограниченного понимания нет.
