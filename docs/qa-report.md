Результат: **37 из 37 автоматических тестов прошли**, ошибок нет. Из них 16 проверяют смысловой движок и раскладку, 21 — интеграцию каталога, SVG-экспорта, разрезания исходников и пользовательских палитр. ## Проверка извлечения исходных SVG

Восстановлены четыре составных исходных листа. Их точные количества path:

| Исходный лист | Path-элементы |
| --- | ---: |
| L / главный | 776 |
| L / фоновый | 776 |
| S / главный | 698 |
| S / фоновый | 776 |
| Всего | 3026 |

В 40 отдельных SVG — те же 3026 path. Для каждого листа независимый тест сравнивает мультимножество всех атрибутов каждого path с объединением десяти выделенных предметов. Сравнение проходит: нет потерянных, дублированных или изменённых элементов; данные d и исходные цвета сохранены. Книга учитывает отдельный исходный мелкий Vector.

Для каждого из 40 предметов независимо вычислены точные границы кубических кривых Безье через экстремумы производной, а не приближённую выборку точек. Проверены охват viewBox, отсутствие чрезмерного пустого поля, соответствие пропорций SVG и каталога. Разрезание не использует растровые изображения или clipPath, скрывающий целиком исходный лист.

Все 40 SVG синтаксически корректны. У каждого проверены node ID происхождения, количество примитивов и SHA-256 из docs/asset-provenance.json.

## Проверка функционального ядра

- Подбор по именам, русским формам слов, синонимам и исключениям; неизвестные имена не подменяются выдуманными объектами.
- Смысловой режим явно локальный и ограничен словарём. Неизвестная тема не создаёт случайную сцену.
- Детерминированные раскладки для S/L и квадратного, горизонтального, вертикального форматов; только разрешённые assetId и один общий масштаб.
- Сохранение относительных размеров исходников.
- Экспорт всех 40 реальных предметов в обоих состояниях и размерах под каждой из трёх исходных палитр: 12 полных комбинаций. Количество path сохраняется, сторонние цвета и растровые вложения не появляются.
- Отдельная сложная SVG-фикстура подтверждает уникализацию градиентов, clipPath и href при дублировании. Геометрия d остаётся неизменной после перекраски и экспорта.
- Недопустимые размеры холста, масштаб, детализация и неизвестные предметы отклоняются. Активный контент и растровые SVG-вложения не принимаются.

## Найденные и исправленные ошибки

1. Неизвестный предмет рядом с известным в одной строке раньше игнорировался. Исправлено автором движка, добавлены регрессии.
2. Дробный индекс фонового оттенка мог давать fill="undefined". Исправлено в SVG-ядре, проверено тестом.
3. В исходниках Figma встречается fill="white"; он раньше не следовал пользовательскому neutral white. Исправлено, проверено тестом.
4. Загруженная палитра пропадала из выбора после переключения на встроенную. Исправлено в src/palette-options.js и src/app.js; тест проходит переход custom → все встроенные → custom.
5. Пользовательский id палитры мог совпасть со встроенным. Теперь каждый импорт получает уникальный custom-ID; тест подтверждает доступность обеих схем и отсутствие мутации каталога.
6. После выделения точного viewBox обновлены размеры каталога, устранено расхождение пропорций coin/S/main.
