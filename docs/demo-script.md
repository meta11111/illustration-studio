# Демонстрация и сдача

Цель — за 1–2 минуты показать оба сценария, ручное редактирование, палитры и настоящий векторный экспорт. Записывать после проверки запуска; если функция не работает, сначала исправить либо явно отметить ограничение.

## Сценарий записи

1. Открыть приложение и показать каталог исходных предметов.
2. В режиме названий ввести «книга, телефон, пазлы». Собрать сцену. Переместить один предмет, повернуть другой, продублировать и поменять порядок слоёв.
3. Переключиться на смысловой подбор. Ввести «Собрать знания воедино». Показать выбранные предметы и объяснение. Указать, что используется локальный словарь.
4. Переключить квадратный, широкий и вертикальный форматы. Показать изменение раскладки.
5. Переключить S/L на предмете с заметной разницей детализации, например телефоне.
6. Сменить главную/фоновую роль и палитру. Загрузить JSON дополнительной палитры.
7. Скачать SVG и открыть его в редакторе векторов/Figma. Показать отдельные редактируемые группы.

Не ускорять запись так, чтобы скрыть ошибки или подменить работу сервиса заранее готовыми картинками.

## Три примера для комплекта

| Пример | Ввод | Что демонстрирует |
| --- | --- | --- |
| Обучение | «Собрать знания воедино» | Метафора, книга/пазлы и объяснимый смысловой подбор |
| Финансы | «Кошелёк, монета, телефон» | Точные названия, слои и исходные пропорции |
| Совместная работа | «Команда собирает решение» | Подбор по теме, фоновые объекты и другой формат |

Фактический набор предметов должен соответствовать реализации словаря. Если формулировка не распознаётся, не представлять её успешным примером; скорректировать словарь и проверить либо выбрать поддерживаемый запрос.

Примеры сохранять отдельными SVG вместе с исходными параметрами сцены, чтобы их можно было воспроизвести.

## Чек-лист передачи

- Работающая ссылка либо запускаемый проект.
- Ссылка на репозиторий исходников; проверить доступ получателя.
- README с командой запуска.
- Короткое описание архитектуры хранения и переиспользования SVG.
- 2–3 примера векторных композиций.
- Демонстрация основного сценария.
- Фактический список AI-инструментов.
- Результаты проверок и известные ограничения.

Не считать частную ссылку доступной работодателю без проверки доступа. Не публиковать предоставленные иллюстрации шире, чем нужно для согласованной передачи тестового.

## Короткое объяснение на собеседовании

«Я извлёк исходные SVG целыми группами и сделал каталог вариантов S/L и главных/фоновых состояний. Запрос выбирает только существующие идентификаторы, затем отдельный алгоритм размещает предметы. Редактор меняет преобразования и палитры, а экспорт собирает самостоятельный SVG. В автономной версии метафоры поддерживаются конечным смысловым словарём; внешнюю языковую модель можно добавить отдельным адаптером».
