# Illustration Studio

Конструктор векторных иллюстраций из исходной библиотеки Figma. Работает локально: отдельный аккаунт, платная модель и API-ключ для запуска не требуются.

## Запуск

Нужен Node.js 20 или новее.

```powershell
node serve.mjs
```

Откройте адрес, который напечатает сервер. Запускайте через HTTP-сервер, а не двойным кликом по `index.html`: браузер загружает SVG и модули с того же адреса.

Установка зависимостей и сборка не нужны. Проект использует нативные ES-модули браузера.

## Основной сценарий

1. Выберите формат холста, детализацию S/L и палитру.
2. Введите названия предметов, например «книга, телефон, пазлы», либо переключитесь на подбор по смыслу.
3. Соберите композицию автоматически или добавьте предметы из каталога.
4. Выделяйте и перемещайте объекты, меняйте поворот, главный/фоновый вариант и порядок слоёв.
5. Скачайте SVG. Предметы остаются векторными группами.

В исходной библиотеке десять предметных тем: книга, телефон, пазлы, монета, наушники, лампа, цветы, кошелёк, папка и ручка. У предметов есть исходные варианты S/L и главные/фоновые состояния.

## Подбор по смыслу

Используется **локальный смысловой словарь**, а не внешняя языковая модель. Он сопоставляет названия, формы слов, синонимы и известные темы с идентификаторами библиотеки. Например, обучение связано с книгой и ручкой, финансы — с монетой и кошельком, совместная работа — с пазлами.

Охват словаря ограничен. Сервис не заявляет универсальное понимание произвольных метафор. Если подходящие предметы не найдены, он сообщает об этом; недостающие изображения не генерируются. Ввод не отправляется стороннему AI-провайдеру.

Выбор предметов отделён от алгоритма раскладки. В будущем интерпретатор можно заменить серверным LLM-адаптером, сохранив тот же проверяемый список допустимых предметов.

## SVG и ограничения исходников

- Предметы извлечены из предоставленных групп Figma без перерисовки.
- Детализация S/L переключает исходный вариант, а не имитируется уменьшением L.
- Предметы используют общий масштаб композиции: их относительные размеры и пропорции сохраняются.
- Перекраска меняет разрешённые цвета, а не геометрию.
- Цвета фона и объектные акценты разделены.
- Экспорт собирает векторную сцену, а не помещает PNG внутрь SVG.
- Каждый экземпляр получает собственные идентификаторы внутренних масок и ссылок, чтобы дубликаты не конфликтовали.

## Дополнительная палитра

Загрузите JSON-файл следующего вида:

```json
{
  "name": "Моя схема",
  "background": ["#D8CEF7", "#AD96E8", "#7861D5"],
  "objects": ["#F7ECA9", "#F49FA7", "#FBE1E2"],
  "ink": "#181817",
  "white": "#FFFFFF"
}
```

`background` задаёт три разрешённых фоновых оттенка, `objects` — три объектных акцента. Точные исходные палитры хранятся в каталоге. Импортированная палитра заменяет цвета по тем же ролям.

## Проверка

```powershell
node --test tests/*.test.mjs
```

Тесты проверяют подбор, раскладку и независимые инварианты библиотеки/экспорта. Актуальные результаты и границы проверки перечислены в [отчёте QA](docs/qa-report.md). Не следует считать один успешный тест подтверждением всех сценариев.

Для ручной проверки экспортируйте сцену с двумя копиями сложного предмета и импортируйте результат в Figma: группы должны остаться редактируемыми, маски и цвета — сохраниться.

## Устройство проекта

| Файл или каталог | Назначение |
| --- | --- |
| `assets/` | Исходные SVG предметов |
| `src/catalog.js` | Соответствия предметов, вариантов и палитр |
| `src/app.js` | Интерфейс и пользовательские действия |
| `src/scene.js` | Данные сцены и общие операции |
| `src/composer.js` | Поиск по названиям, смысловой подбор и раскладка |
| `src/svg.js` | Загрузка, перекраска, отображение и экспорт SVG |
| `docs/asset-provenance.json` | Происхождение исходников и контрольные суммы |
| `tests/` | Автоматические проверки |

Подробнее: [архитектура](docs/architecture.md), [демонстрация](docs/demo-script.md), [критерии приёмки](docs/acceptance-checklist.md).

## AI-инструменты при разработке

ChatGPT/Codex использован для декомпозиции, написания кода, подготовки документации и проверки решения. Работа распределялась между агентами: исходники, редактор, автосборка и независимая проверка. Наличие нескольких агентов не заменяет проверку запуска и экспорта.

Figma использована как источник предоставленных векторных материалов. Изображения внешними генеративными моделями не создавались.
